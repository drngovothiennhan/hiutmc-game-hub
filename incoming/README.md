# Thư mục nhận kết quả từ ChatGPT/Gemini

Thả file kết quả vào đây (nút Add file > Upload files). Thư mục này **không** nằm trong `public/`, nên không ảnh hưởng ứng dụng đang chạy. Claude sẽ kiểm tra rồi mới nạp vào ngân hàng ca.

Đặt tên file: `YYYY-MM-DD_viec-N_ten-ai.json` (hoặc `.csv`). Ví dụ `2026-10-06_viec-1_chatgpt.json`.
